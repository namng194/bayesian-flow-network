## 🚀 Quick Start


**Or step-by-step (recommended — lets you check each stage):**

```bash

bash scripts/00_setup.sh

# Step 1 — fastest experiments first (no training needed)

python ../../scripts/exp2a_nsteps_ablation.py          # ~1h
python ../../scripts/exp3_flow_visualizer.py           # ~30 min
python ../../scripts/exp2c_generate_samples.py         # ~30 min

# Step 2 — baselines (parallel if 2 terminals available)
python ../../scripts/exp1a_train_ddpm.py --dataset cifar10 --quick  # ~3h
cd ../nanoDD
python ../../scripts/exp2b_train_d3pm.py --quick                    # ~5h

# Step 3 — aggregate
cd ../bayesian-flow-networks
python ../../scripts/exp1b_sampling_time.py
python ../../scripts/exp2d_plot_results.py
python ../../scripts/exp_final_plots.py
```

## 🔬 Experiments Breakdown

### Exp 1 — DDPM baseline + Speed comparison (Continuous Image)
*   **Scripts:** `exp1a_train_ddpm.py`, `exp1b_sampling_time.py`
*   **Dataset:** CIFAR-10 (32×32)
*   **Key Claim:** BFN reaches near-optimal quality at 50–100 steps natively. DDPM needs DDIM + schedule engineering to do the same.

| Mode | Steps | Est. time | Expected FID |
| :--- | :--- | :--- | :--- |
| `--quick` | 100k | ~3h | ~15–25 |
| `full` | 800k | ~15h | ~3.5–4.5 |

### Exp 2 — BFN vs D3PM comparison (Discrete Text)
*   **Scripts:** `exp2a_nsteps_ablation.py`, `exp2b_train_d3pm.py`, `exp2c_generate_samples.py`
*   **Dataset:** text8 (character-level, 27-char alphabet, length-256)
*   **Metric:** BPC — bits per character (↓ better)
*   **Key Claim:** BFN probability simplex inputs are differentiable, allowing it to natively outperform standard discrete diffusion (D3PM).

**D3PM Baseline Training Options:**
```bash
# Quick mode (recommended for 2-week timeline)
python scripts/exp2b_train_d3pm.py --quick    # ~5h → ~1.50 BPC

# Full mode (reproduces nanoDD paper result)
python scripts/exp2b_train_d3pm.py            # ~25h → ~1.37 BPC

# Fastest fallback: use pretrained nanoDD checkpoint
# Yields ~1.37 BPC instantly.
```

### Exp 3 — Bayesian Flow Visualization (The "Living Demo")
*   **Script:** `exp3_flow_visualizer.py`
*   **Purpose:** The seminar's most intuitive visual for Q&A and slides.
*   **Generates:**
    1.  **MNIST Flow Grid:** Images crystallizing from a uniform prior → sharp digits.
    2.  **Text8 Simplex Heatmap:** X-axis = position, Y-axis = character, Color = probability. Watch entropy visibly collapse.
    3.  **Entropy Collapse Curve:** Plots $H(\theta_t)$ in bits vs $t$, overlaid with DDPM's noise schedule $\sigma(t)$.

### Final — Aggregated Slide-Ready Figures
*   **Script:** `exp_final_plots.py`
*   **Purpose:** Aggregates all logs into 4 presentation-ready figures:
    *   `FINAL_fig1_comparison_table.png`: All models vs BFN (text8 BPC + CIFAR bpd).
    *   `FINAL_fig2_speed_quality.png`: Dual-axis (BPC vs n_steps & ms/sample vs n_steps).
    *   `FINAL_fig3_entropy_collapse.png`: BFN entropy curve vs DDPM noise schedule.
    *   `FINAL_fig4_sample_grid.png`: BFN / DDPM side-by-side visual samples.
